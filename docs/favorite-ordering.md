# Favorite order

Choose **Reorder favorites** in the Favorites tab, or **Reorder hymns** in a
favorite category's menu. Drag a handle to place a hymn in its desired position.
The order saves automatically and remains after restarting. Main Favorites and
each category have independent orders; adding a new hymn still places it first.

Reader navigation and autoplay use the selected list's order. Reordering keeps
the original book identities, including entries for books that are unavailable.
Those entries appear as unavailable in the ordering screen instead of being
discarded. Existing saved-data protection stops edits if storage fails and shows
the retry notice.

This does not create repeated playlist entries or mix Scripture readings into
Favorites. Ordered worship-service playlists remain a separate roadmap feature.
