# UX requirements for roadmap work

Roadmap progress must preserve the established experience. New language content
uses shared screens and controls; it must not replace familiar interactions with
an unrelated workflow just because an import uses a different data structure.

- Numbers always means the number pad, in both Modern and Classic.
- Group related editions under one language choice. English and Spanish each
  offer both Old/New results for the entered number. Single editions show one
  result without a disabled second-book button.
- Keep numbers, search, favorites, settings, reader navigation, and saved book
  identities consistent across languages. Recent chips belong to the current
  language. Topic lists retain their native organization and selected queues.
- Share reading controls: text size, favorites, copy/share, reporting, and
  opt-in auto-scroll. Imported text uses an adjustable reading-time estimate
  until matched music exists; English keeps its MIDI timing.
- Only expose music actions backed by the correct edition's media. Missing
  audio is a content gap to solve, never permission to play a same-number song
  from another language. Do not imply that lyrics-only editions have full music
  parity. Existing English music controls must remain intact.
- Avoid extra persistent controls and duplicate selectors. Put secondary actions
  in existing menus; inspect small-screen layouts before calling work complete.
- Validate both designs, light/dark modes, long native titles, larger text,
  correct edition selection, and retained English behavior. Feature checkboxes
  are not a substitute for checking the rendered experience.
