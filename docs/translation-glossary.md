# Interface translation glossary (es / pt / ru)

Use one term per concept for new strings. Established by the 13 October 2026
AI-assisted terminology review; a fluent human review is still required
(see [interface-translations.md](interface-translations.md)).

**Conventions**
- **Spanish:** Latin American, as in the *Himnario Adventista*. Address the user as **tú** ("Elige", "Toca", "Escribe"). Use sentence case, «» quotes, ¿…? and ¡…!, and "video" without an accent.
- **Portuguese:** Brazilian, as in the *Hinário Adventista do Sétimo Dia* (1996). Use **você** imperatives ("Toque", "Escolha", "Digite"), sentence case and “ ” quotes. Settings descriptions take the 3rd-person indicative ("Mostra…", "Usa…").
- **Russian:** formal **вы** ("Нажмите", "Выберите"), «» quotes and ё where conventional. Every count needs a `one/few/many/other` plural, including "процент".
- **Never translate:** "Old & New SDA Hymnal", "Sabbath Programs", hymn titles (e.g. "Amazing Grace"), book and edition names passed in `{book}`, `{newBook}` and `{oldBook}`, stored IDs, musical note names, MIDI, iPhone, HTML.
