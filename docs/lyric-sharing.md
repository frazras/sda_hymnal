# Copying and sharing lyrics

Open a hymn's reader menu and choose **Copy or share lyrics**. The preview starts
with the full hymn. **Include** selects an individual verse, refrain, or source
paragraph; unnumbered paragraphs are called sections rather than inventing verse
numbers. The preview itself supports text selection.

**Copy** puts the preview on the clipboard. **Share** opens the device's normal
share sheet; the user chooses the recipient or destination. Cancelling the sheet
does not report a successful send. If sharing is unavailable, Copy remains usable.
The share button supplies a popover anchor for iPad.

Both actions include the title, number, and edition. Export removes HTML markup,
decodes entities, preserves Unicode and lyric line breaks, and uses original
source order. It does not repeat refrains automatically or normalize accents as
search does. Sharing sends text only, without audio, videos, or score images.

Validation includes English verse/refrain boundaries, Cyrillic and entity
preservation, every imported hymn's nonblank lines, selected-verse clipboard
content, the native-share payload, and compact layouts in both app designs.
