# Reading history

Open **Settings → Reading history** to see previously opened hymns from every
installed book, most recently opened first. Reopening a hymn moves it to the top
instead of adding duplicate rows. Each row includes its edition so identical
numbers in different books remain distinct. The existing quick Recent chips on
the number screen remain available.

History keeps visits beyond the former six-entry limit. The six references
retained by older versions are preserved; visits already discarded by those
versions cannot be recovered. Entries from unavailable books remain saved and
are labelled unavailable until their book returns.

The trash button asks before clearing history. Clearing does not change
favorites, categories, selected books, or other settings. Storage errors pause
changes and show the existing saved-data recovery notice. Returning to an
available hymn from history uses that hymn's own book for previous/next reading.
